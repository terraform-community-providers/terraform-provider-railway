# Railway Provider

This provider is used to interact with the many resources supported by [Railway](https://railway.app).

## Authentication

This provider requires one Railway API token.

Use an account or workspace token for the full selection of resources. Use a project token for reads and actions that Railway permits within that project.

Choose one authentication mode for each provider configuration:

* Set the sensitive `token` argument or the `RAILWAY_TOKEN` environment variable for account and workspace tokens. These use bearer authentication.
* Set the sensitive `project_token` argument or the `RAILWAY_PROJECT_TOKEN` environment variable for project tokens. These use Railway project-token authentication.

Do not set both token kinds for one provider configuration.

## Example Usage

```terraform
variable "railway_token" {
  type      = string
  sensitive = true
}

variable "railway_project_token" {
  type      = string
  sensitive = true
}

provider "railway" {
  token = var.railway_token
}

provider "railway" {
  alias         = "project"
  project_token = var.railway_project_token
}
```
